# 模拟面试接口 Apifox 测试用例使用说明

## 文件位置

- 测试集合：`docs/mock-interview-apifox-testcases.json`
- 格式：Postman Collection v2.1（Apifox 可直接导入）

## 导入步骤

1. 打开 Apifox，进入目标项目。
2. 点击左侧「导入」按钮（或按 `Ctrl + I` / `Cmd + I`）。
3. 选择「文件导入」，上传 `mock-interview-apifox-testcases.json`。
4. 导入完成后，左侧目录会出现「模拟面试接口测试集」。

## 配置环境变量

导入后请修改集合中的变量（Apifox 中叫「环境」或「集合变量」）：

| 变量名 | 默认值 | 说明 |
|---|---|---|
| `baseUrl` | `http://localhost:8088` | 服务地址 |
| `userId` | `1` | 当前登录用户 ID |
| `resumeId` | `1` | 用于创建模拟面试的简历 ID |
| `sessionId` | `1` | 创建模拟面试后返回的 sessionId |
| `questionId` | `1` | 该 session 下第一个题目的 id |

> 建议：在 Apifox 中创建一个「本地测试」环境，把上述变量放进去，方便切换。

## 推荐执行顺序

用例编号已经按依赖关系排好，建议按以下顺序执行：

1. **01 创建模拟面试 - 正常**
   - 执行成功后，从响应 `data` 中拿到 `sessionId`，更新到变量中。
2. **04 获取模拟面试列表**
   - 确认列表中出现了刚创建的 session。
3. **05 获取模拟面试详情**
   - 确认返回了题目列表，从第一个题目拿到 `id`，更新到 `questionId` 变量。
4. **06 更新状态 - PRACTICING**
5. **08 保存练习进度 - 正常**
6. **11 删除模拟面试**
7. **12 删除后再查详情**
   - 预期返回不存在。

其余用例（02、03、07、09、10、13）为异常场景，可随时执行。

## 注意事项

- **创建接口会调 LLM**，耗时 10~60 秒，请确保环境变量 `ARK_API_KEY_DEEPSEEK` 已配置。
- 如果数据库里没有简历，先用简历上传/保存接口准备一份简历，把 `resumeId` 更新到变量里。
- 越权测试用例（13）使用了 `X-User-Id: 2`，请确保数据库里存在 userId=2 且有另一份简历/模拟面试，或者只是验证返回「无权访问」即可。
