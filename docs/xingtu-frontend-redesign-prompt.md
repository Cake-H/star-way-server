# 一、视觉风格规范（科幻感核心）

## 1. 色彩体系（深空基调，禁止浅色大底）
- 背景主色：深空黑蓝 `#050914` → `#0B1026` 的纵向渐变，局部叠加星云色块（径向渐变的紫/青雾状光晕，透明度 8%–15%）
- 主品牌色：星云紫 `#8B5CF6`（主按钮、选中态、进度指示）
- 辅助色：星际青 `#22D3EE`（链接、数据高亮、AI 相关元素）
- 点缀色：流星金 `#FBBF24`（成就、奖励、CTA 强调；星能余额数字可用金色点缀），用量克制，仅作点睛
- 文字：主文字 `#E5E9F0`，次要文字 `#8B93A7`，禁用文字 `#4A5265`
- 卡片/容器：玻璃拟态 `rgba(139, 92, 246, 0.05)` 底 + `1px rgba(139, 92, 246, 0.15)` 描边 + `backdrop-filter: blur(12px)`
- 状态色补充（功能需要）：成功 `#34D399`、警告 `#FBBF24`、错误 `#F87171`，需与深空底协调（降低饱和度、用于小面积）

## 2. 星空宇宙元素（必须实际实现，不是贴图了事）
- **动态星空背景**：全页面底层的粒子星场（Three.js / react-three-fiber，或轻量 Canvas 实现），星星带微闪烁（twinkle）效果，随鼠标产生轻微视差
- **流星**：每隔 8–15 秒随机划过一颗流星（带拖尾渐隐），首页 Hero 区密度稍高
- **星云光晕**：关键区块背后放置大半径模糊渐变光斑（紫/青双色），营造空间纵深
- **星座连线**：「你的星途」流程时间线、模拟面试逐题进度用"星座连线"样式表达（节点发光圆点 + 细线连接，已点亮节点亮起，未到达节点暗淡呼吸）
- **行星/轨道装饰**：功能卡片角落可用低透明度轨道弧线装饰

## 3. 光效与质感
- 按钮 hover：外发光 `box-shadow: 0 0 20px rgba(139,92,246,0.4)` + 1.03 倍缩放，过渡 200ms
- 卡片 hover：描边亮度提升 + 顶部出现一道 2px 的青→紫渐变光带扫过
- 重要 CTA 按钮：渐变底（紫→青）+ 微光晕脉冲呼吸动画（3s 循环，克制使用，全页不超过 2 处）
- 分割线不用实线，用渐隐的光线（中间亮两端透明）

## 4. 字体
- 标题/数字：未来感字体（英文 Orbitron / Space Grotesk，中文思源黑体 Bold），关键数字可加等宽处理（星能余额、题目编号等数据数字一律等宽）
- 正文：思源黑体 Regular / Inter，字号不小于 14px，行高 1.6 保证可读性
- 标题层级对比强烈：PC 端 H1 48–64px → H2 32px → H3 24px

## 5. 动效（GSAP / Framer Motion）
- 页面入场：元素从下方 24px 处淡入 + 依次 stagger 0.08s
- 滚动视差：星空层、星云层、内容层三层不同速率移动
- 数字滚动：统计数据用 count-up 动画
- 所有动效时长 ≤ 500ms，缓动用 `cubic-bezier(0.16, 1, 0.3, 1)`；支持 `prefers-reduced-motion` 时关闭粒子与视差

# 二、首页布局与内容结构（C 端 Web App）

1. **导航栏**：固定顶部、滚动时玻璃拟态加深；左侧 Logo（星轨图形 + "星途"）；中间导航项：**首页 / 简历（星舰档案）/ 网申投递（星港导航）/ 模拟面试（跃迁试炼）/ 面试复盘（航行日志）**；右侧：星能余额胶囊（金色数字，点击进入额度中心）+ 用户头像入口
2. **Hero 区（首屏全屏）**：左侧大标题（如「穿越星海，抵达你的新星」）+ 副文案（一句话说清产品闭环：AI 解析简历 → 一键网申投递 → 模拟面试 → 面试复盘）+ 主 CTA（**「上传星舰档案，开启星途」**，直达简历上传）+ 次 CTA（「探索星港」跳转站点目录）；右侧/背景为动态星空与一颗缓慢旋转的星球；底部 3 个核心数据（count-up）：数据项从接口/配置读取（如「已助力 10,000+ 旅人抵达新星」、「支持网申站点数」、「每日免费星能 10 点」、「累计生成试炼题数」），**未接入真实统计前用占位数据并标注 TODO，禁止编造营销数字**
3. **核心功能区**：4 张玻璃拟态卡片，Bento 不对称网格（2 大 2 小），每卡「图标 + 通俗名 + 隐喻副标题 + 一句话说明 + 入口」，hover 有光带扫过：
   - **简历管理 · 星舰档案**（大卡）：上传文件 AI 解析为结构化档案，多份档案随时切换
   - **网申投递 · 星港导航**（大卡）：目的地站点目录 + 插件光速填表，网申不再重复劳动
   - **模拟面试 · 跃迁试炼**：AI 按你的简历出题，逐题试炼、断点续练
   - **面试复盘 · 航行日志**：录音一句话，AI 整理成结构化复盘
4. **"你的星途"流程区**：星座连线时间线展示真实求职旅程五阶段：**星舰建档（上传解析简历）→ 星能补给（每日领取额度）→ 星港投递（站点+插件填表）→ 跃迁试炼（模拟面试）→ 航行复盘（复盘后抵达新星）**；登录后按用户真实数据点亮节点（如：有简历→建档亮；有模拟面试→试炼亮），未到达节点暗淡呼吸并可点击跳转对应功能
5. **「舰载导航」浮动入口**：右下角发光圆球（呼吸灯效果）。**注意：系统没有 AI 对话后端**，此入口重定义为「导航与帮助中枢」——点击展开快捷面板：功能快捷跳转、3 步新手引导回看、常见问题、⌘K 快捷搜索；UI 形态保留浮球+面板设计，不做聊天输入框（或在输入框位置明确标注「对话能力即将上线」占位）
6. **个人星图看板预览**（登录后首页区块）：以"星图雷达图 / 轨道环形图"可视化**真实用户数据**：星能余额环形图（金/紫双色）、模拟面试完成度（COMPLETED/总数）、面试复盘场次数、近期星能流水迷你趋势；深色底 + 青紫数据色；未登录时该区块替换为登录引导
7. **页脚**：低透明度星座图案装饰，常规链接分组

# 三、功能页面设计清单（每页均需 PC + 移动双端设计）

> 所有页面遵循同一主题；以下只列每页的功能性设计要点与状态要求。

## 1. 登录页 `/login`
- 深空全屏 + 中央玻璃拟态卡片；手机号输入（实时格式校验）+ 验证码输入（6 位，自动分格）+「发送验证码」按钮（60s 倒计时，倒计时中禁用）
- 文案隐喻：「登舰验证」；登录即自动注册需有一行提示
- 移动端：单列、输入框 ≥44px、唤起数字键盘

## 2. 简历列表页 `/resume`（星舰档案库）
- 卡片式简历列表（名称/更新时间/默认标识），默认简历有发光描边标识；「上传新档案」主 CTA
- 上传流程：文件选择（前端先校验格式与大小）→ 解析中全屏/卡片 loading（「舰载 AI 正在解析星舰档案…」+ 提示本次消耗星能）→ **草稿确认页**（结构化分区展示，可编辑，明确「确认入库」主按钮，草稿不落库的提示常驻）
- 删除需二次确认弹窗；删除默认简历时提示「默认档案将自动切换为最近更新的档案」
- 移动端：卡片纵向流，操作（设默认/编辑/删除）收进卡片右上角菜单

## 3. 简历详情/编辑页 `/resume/[id]`
- 按真实结构分区：基本信息 + 9 类可重复模块（教育/工作/项目/奖项/证书/语言/校园/论文/技能），每模块可增删条目
- PC：左侧模块锚点导航（星座连线样式）+ 右侧表单区；移动端：手风琴折叠分区
- 保存前校验必填项；保存成功 toast

## 4. 网申站点目录页 `/apply-sites`（星港导航）
- 顶部分类 Tab（横向滚动，选中态紫色发光下划线）+ 站点卡片网格（logo/名称/分类标签）
- `supportAutofill=1` 站点带「光速填表」青色徽章，点击展开插件安装/使用引导弹层；不支持 autofill 的站点点击外链跳转（新窗口，有外链提示）
- 移动端：Tab 横向滑动，卡片单列

## 5. 模拟面试列表页 `/mock-interview`（跃迁试炼）
- 卡片列表：标题/题数/状态徽章（GENERATED 待试炼=青色呼吸 / PRACTICING 试炼中=紫色常亮 / COMPLETED 已完成=金色点亮）/更新时间
- 「发起新试炼」主 CTA → 选择简历弹窗（默认简历预选）→ 生成中 loading 全屏（「AI 考官正在生成试炼题库…（约 3-10 秒）」，带进度感文案轮播）
- 删除二次确认

## 6. 模拟面试练习页 `/mock-interview/[id]`
- 逐题练习界面：题目区（玻璃卡片）+「展开参考答案」按钮（展开态会持久化）+ 评分维度展示 + 参考答案区（青紫渐变描边区分）
- 顶部/侧边：星座连线式题目进度条（当前题发光，已练题点亮，可点击跳题）
- 进度自动保存（当前题+答案展开态），刷新/离开后可断点续练；完成全部题目后引导「完成试炼」→ 状态流转 COMPLETED + 抵达新星庆祝动效（克制，一次性）
- PC：左侧题目导航 + 右侧答题区；移动端：纵向卡片流 + 底部「上一题/下一题」固定操作栏

## 7. 面试复盘列表页 `/interview`（航行日志）
- 按时间倒序的场次卡片（公司/岗位/轮次/日期/题数），「记录新复盘」主 CTA

## 8. 面试复盘创建/详情页 `/interview/sessions/[id]`
- 核心 AI 流程：录音上传（multipart，显示录音/上传状态）或口述文本输入 → 「舰载 AI 正在整理航行日志…」→ **草稿确认视图**：场次信息（公司/岗位/轮次/日期/标题）+ 多题卡片（题干/我的回答/AI 评价/参考答案/备注），全部可编辑，明确提示「草稿尚未保存，确认后入库」→「确认入库」落库
- 已保存场次：题目增删改，部分更新（null 不改/空串清空的交互要体现在编辑表单中）
- 移动端：录音按钮大触控区，草稿卡片纵向流

## 9. 额度中心页 `/quota`（星能补给站）
- 顶部：星能余额大数字（金色、等宽、count-up）+ 会员等级徽章 + 每日补给状态（今日已领/未领）
- 兑换码充值卡片：输入框 +「兑换」按钮，格式实时校验，成功/失败明确反馈
- 额度流水列表：类型图标（每日补给/消耗/兑换/调整）+ 正负点数（+青 / -紫）+ 时间 + 关联业务；PC 表格，移动端卡片列表
- **全局 30200 拦截**：任何 AI 操作返回 30200 时弹出统一弹窗——「星能不足：本次操作需要 X 点，当前剩余 Y 点。每日登录可领取 10 点补给，或输入补给密令立即充值」+ [去充值] [明日再来]

## 10. 我的页面 `/user`（移动端头像入口，PC 收进头像下拉）
- 账号信息（脱敏手机号）、星能入口、新手引导回看、退出登录（二次确认）

# 四、管理后台与浏览器插件（主题统一，形态从简）

## 管理后台（星际航管中心）
- **功能零变更**：管理员登录、用户管理（分页/详情/手动调额+必填备注）、用量看板（按天趋势/按业务占比/Top 用户）、兑换码管理（批量生成 1-1000 张+明码仅此一次返回需导出、列表、禁用）、网申站点管理（CRUD+上下架）
- 视觉：同套深空色彩 token 与玻璃拟态，但**效率优先**——密度更高的表格、克制的装饰（无粒子星场或仅登录页保留）、数据图表用青紫金配色
- 兑换码批量生成成功后的明码展示必须有「一键导出/复制」和「关闭后不再显示」警示

## 浏览器插件（弹窗 + 页面内 UI）
- 仅做视觉主题统一（深空玻璃拟态、青紫强调色），适配插件弹窗 ~400px 宽度约束
- 一键填表异步任务：步骤条（phase）+ percent 进度条 + 轮询状态；SUCCEEDED 后展示 `assignments` 回填摘要与 `blockedFields` 需人工项（标红+引导）；失败给出原因与重试
- 简历选择器：只读列表选择 + 预览；填表前置提示「请先展开表单中的 +添加 区块」（基于 autofill-context 条目数）

# 五、双端适配规范（PC + 移动端，双端同等质量）

## 0. 核心原则
**不是"缩放适配"，而是"同主题双设计"**：PC 端与移动端要分别做信息架构和布局设计。凡因屏幕尺寸差异导致模块无法优雅呈现的，必须为移动端重新设计布局和交互形态，禁止只做断点压缩、横向挤压、字号硬缩这种偷懒式适配。两端的视觉品质、功能完整性、操作效率必须一致。

## 1. 断点与设计基准
- 桌面端 ≥1024px（以 1440px 为主设计稿）
- 平板 768–1023px（布局介于两者之间，逐模块判断走桌面方案还是移动方案）
- 移动端 <768px（以 375px 为主设计稿）

## 2. 必须重新设计（而非缩放）的模块
- **导航**：PC 为顶部水平导航（含星能余额胶囊）；移动端重新设计为"顶部精简栏（Logo + 星能胶囊 + 头像）+ 底部 Tab Bar（5 个核心功能：**首页 / 档案 / 星港 / 试炼 / 日志**，图标 + 文字，玻璃拟态底）"，次级功能（额度中心、设置、引导回看）收进头像入口的抽屉菜单。底部 Tab 需避开手机安全区（safe-area-inset）
- **Hero 区**：PC 左右分栏（文案左、星球右）；移动端改为上下堆叠，标题缩至 28–32px，星球缩小并退为背景装饰（透明度降低、不抢占内容焦点），CTA 按钮全宽
- **核心功能区**：PC 的 Bento 不对称网格在移动端不可压缩，重新设计为纵向卡片流或横向滑动卡片（scroll-snap 逐卡吸附 + 进度指示点）
- **"你的星途"时间线**：PC 横向星座连线；移动端重新设计为纵向时间线（发光节点沿左侧竖线排列，内容卡片在右侧）
- **数据看板**：PC 多图并排仪表盘；移动端重新设计为单图卡片轮播（每次一图 + 指示点），图表简化（减少坐标轴标签、增大字号和触控热区）
- **表格与列表**：PC 端用表格呈现的数据（额度流水、后台用户列表等），移动端一律改为卡片列表——字段重排、关键信息前置（金额/状态）、次要信息折叠
- **「舰载导航」入口**：PC 右下角浮球点击展开侧边快捷面板；移动端点击展开为底部抽屉（bottom sheet，可上拉全屏、下滑收起）
- **模拟面试练习页**：PC 左侧题目导航 + 右侧答题；移动端纵向题目卡片 + 底部固定「上一题/下一题」栏
- **表单**：PC 允许多列表单；移动端一律单列，输入控件高度 ≥44px，唤起正确的键盘类型（手机号/验证码 → 数字键盘）

## 3. 触控与交互差异
- 移动端所有可点目标 ≥44×44px，间距充足防误触
- 依赖 hover 的效果（光带扫过、发光）在移动端降级为按下态反馈；**任何功能不得只能通过 hover 触发**
- 移动端合理使用手势：卡片滑动切换、抽屉拖拽收起
- 两端滚动行为分别调优：PC 视差保留，移动端视差简化或取消

## 4. 星空动效的双端性能策略
- 移动端粒子数量减半、流星频率降低、关闭鼠标视差
- 运行时检测掉帧即自动降级：粒子减少 → 最终降级为静态星空背景图
- 页面不可见时两端均暂停动画循环
- 图片资源用响应式加载（srcset / sizes），移动端不加载桌面大图
- **管理后台默认关闭粒子星场**（效率优先），仅登录页可保留轻量版

## 5. 双端验收清单（输出前逐条自查）
- [ ] 移动端无任何横向滚动条、无内容溢出、无不合理留白
- [ ] 移动端正文字号 ≥14px，无小于 12px 的文字
- [ ] 两端所有功能完整可用，操作路径同样高效（移动端不得出现"此功能请前往 PC 端"）
- [ ] 两端均通过真机/模拟器宽度逐一验证：1440 / 1024 / 768 / 390 / 375 / 360

# 六、必须遵循的十大可用性原则（尼尔森启发式评估，逐条落地）

1. **系统状态可见**：所有异步操作必须有明确状态——简历解析「舰载 AI 正在解析星舰档案…」、模拟面试生成「AI 考官正在生成试炼题库…（约 3-10 秒）」、语音复盘「舰载 AI 正在整理航行日志…」、插件填表 phase 步骤条 + percent 轮询、验证码 60s 倒计时；列表页用骨架屏
2. **系统与现实匹配**：功能名称一律「通俗名 + 隐喻副标题」（如主标题"AI 模拟面试"，副文案"跃迁试炼"），图标必须配文字标签；涉及钱/额度的概念（星能余额、消耗点数）必须同时显示具体数字，不允许只有隐喻没有数字
3. **用户控制与自由**：**简历解析草稿与复盘草稿 AI 生成后不落库**，UI 必须有明确的「草稿待确认」态 + 「确认入库」主操作 + 「重新生成」入口；删除简历/模拟面试/复盘场次需二次确认（复盘删除需说明级联删除题目）；弹窗可 ESC 关闭
4. **一致性与标准**：全站按钮层级（主/次/幽灵）样式统一；相同操作在不同页面位置一致；遵循平台惯例（logo 点击回首页等）；**同一功能在 PC 与移动端的入口命名、图标、操作流程保持一致**（底部 Tab 与顶部导航同名词）
5. **错误预防**：手机号/验证码/兑换码实时校验、提交中禁用按钮防重复提交、必填项明确标注；上传简历前置校验文件格式与大小，失焦即提示而非提交后才报错
6. **识别而非记忆**：导航当前位置明确高亮（PC 顶部导航与移动端底部 Tab 同步高亮）；默认简历有常驻标识；模拟面试断点续练（回到上次题目+答案展开态）；最近编辑的简历/最近的复盘置顶可见，不让用户回忆信息
7. **灵活高效**：PC 端 ⌘K 唤起「舰载导航」快捷面板（功能跳转/搜索）；老用户可跳过新手引导；简历列表提供「设为默认」快捷操作
8. **美观简约**：每屏只突出一个主操作（如练习页主操作永远是「下一题/完成试炼」）；装饰元素不得干扰内容阅读；信息密度适中，留白充分
9. **错误识别与恢复**：错误提示用人话说明"发生了什么 + 怎么解决"并提供重试——**30200**：「星能不足：本次操作需要 X 点，当前剩余 Y 点。每日登录可领 10 点补给，或输入补给密令立即充值」[去充值][明日再来]；「档案解析失败：文件过大，请上传 10MB 以内的 PDF」[重新上传]；「试炼题库生成超时」[重试]
10. **帮助与文档**：新用户首次进入有 3 步轻量引导（上传星舰档案 → 领取每日星能 → 选择目的地星港，可跳过、可从「舰载导航」面板回看）；复杂功能旁有 ? 图标悬浮说明（移动端改为点击弹出），插件填表、草稿确认两处必须配说明

# 七、技术与质量约束

- 技术栈：React + TypeScript + Tailwind CSS + shadcn/ui，动效用 Framer Motion / GSAP，星空用 react-three-fiber 或 Canvas
- **接口对接**：后端接口已有完整定义（Apifox/Swagger 用例见项目 docs/），前端必须按现有接口字段对接，**不得虚构接口或字段**；注意：站点 ID 等雪花 ID 以字符串传递（超 JS 安全整数）；录音上传用 multipart
- **性能**：首屏 LCP < 2.5s；星空层用 `requestAnimationFrame` 且页面不可见时暂停；移动端按第五节策略降级
- **无障碍**：文字与背景对比度 ≥ 4.5:1；所有交互可键盘到达且有 focus 可见态（青紫色焦点环）；装饰性动画元素 `aria-hidden`
- 禁止使用：廉价的全屏闪烁星空 GIF、过度的霓虹跑马灯、影响阅读的动态背景文字
