# 隐私政策

> 版本：v1.0（模板，上线前需法务审核）
> 生效日期：____年__月__日

星途智能求职助手（以下简称"我们"）非常重视您的个人信息与隐私保护。本政策说明我们收集哪些信息、如何使用、如何保护以及您的权利。

## 一、我们收集的信息

| 类别 | 内容 | 用途 |
|---|---|---|
| 账号信息 | 手机号 | 短信验证码登录、账号唯一标识 |
| 简历信息 | 姓名、性别、出生日期、证件号码、手机号、邮箱、QQ/微信、地址、紧急联系人、教育/工作/项目经历等 | 简历管理、一键填表、模拟面试等核心功能 |
| 面试记录 | 您口述/填写的面试复盘内容、模拟面试记录 | 面试总结与训练 |
| 使用数据 | AI 调用次数、Token 用量（不含 prompt 内容） | 额度计量与计费 |

## 二、信息的存储与保护

1. **加密存储**：简历中的姓名、手机号、邮箱、证件号码、QQ、微信、地址、紧急联系人等敏感字段使用 AES-256 加密后落库；登录手机号使用确定性加密存储，任何人员直接查阅数据库均无法获得明文。
2. **传输加密**：全站接口通过 HTTPS 传输。
3. **文件存储**：简历原件存储于私有权限的对象存储（OSS），仅通过带时效的签名 URL 访问，不存在公开直链。
4. **日志脱敏**：系统日志不记录明文手机号等敏感信息。

## 三、向第三方传输信息的说明

1. **AI 大模型服务（DeepSeek）**：简历解析、一键填表、面试总结、模拟面试功能需要将相关文本发送给大模型处理。**发送前我们会对文本中的手机号、身份证号、邮箱进行占位符脱敏**（如替换为 `[PHONE_1]`），映射关系仅保留在本次请求的内存中并随请求结束销毁，模型返回后再于服务端还原。第三方模型不会接触到您的上述明文敏感信息。
2. **语音转写服务（阿里云 NLS / OpenAI Whisper）**：面试语音复盘功能会将您的录音传输给转写服务提供商以转换为文字。
3. **短信服务（阿里云短信）**：登录验证码通过短信服务商下发，仅传输您的手机号。

除上述为提供核心功能所必需的情形外，我们不会向任何第三方提供您的个人信息。

## 四、您的权利

- **查询与更正**：您可随时在应用内查看、修改您的简历与个人信息。
- **删除**：您可逐份删除简历、面试记录。
- **账号注销**：您可在应用内"设置 → 账号注销"发起注销。注销后我们将删除或匿名化您的个人信息（手机号不可逆改写、简历与面试记录删除），该操作不可恢复。

## 五、数据保留

- 账号存续期间，我们保留为您的服务所必需的数据。
- 账号注销后，除法律法规另有要求外，您的个人数据将被删除或匿名化；诊断性统计数据（已脱敏）最长保留 90 天。
